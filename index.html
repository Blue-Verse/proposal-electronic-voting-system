핵심 요구사항 분석

  • 투표자 인증: PASS 휴대폰 본인인증 필수 + 간편 인증 등 다중 인증 방식 지원
  • 투표 진행: 안전한 투표 입장 → 선택지 선택 → 투표 완료의 단순·직관 플로우
  • 외부 시스템 3종 연동: KT 전자투표(공지·발송), 데이터리움(공인전자문서), PASS(본인인증)
  • 관리자 웹: 투표 생성·관리, 투표자 등록·관리, 실시간 투표율·결과 집계, 문자 발송 관리, 공인전자문서 연동 상태 관리
  • 반응형 웹: 사용자용 PC/모바일 동시 지원, 관리자용 PC Web
  • 비기능 요구: 대규모 동시 접속 안정성, 무결성·개인정보 보호, 신뢰성·투명성, NCP 기반 확장성
  • 인프라: 네이버 클라우드 플랫폼(NCP) 기반 운영 환경 구축 및 운영 가이드 제공
  • 산출물: 상세 기획서·화면설계서·DB 설계서·디자인 원본·소스 코드·API 문서·운영 가이드 일체

제안 포인트

1. 외부 API 다중 연동 수행 경험 — NICE KYC(CheckPlus, SafeKey, NPAC), 본인인증, 가상계좌 자동화(Seyfert/PayGate), VC 펀드용 NICE KYC 등 정부 규제 환경에서 외부 인증·결제·문서 시스템 15종 이상을 안정적으로 연동한 경험이 있습니다. PASS·KT 전자투표·데이터리움 3종 연동도 동일한 패턴으로 안정적으로 처리합니다.

2. 참고 사이트 분석 기반 기능 설계 — wrione(우리함께 전자투표)와 uvoteform(U+Vote) 두 사이트를 분석한 결과, 다음 기능을 PRD에 우선 반영했습니다.

  • 다중 인증 방식 분리(PASS / 간편 인증) 및 투표 유형별 선택지(찬·반, 택일, 다중 선택)
  • 관리자 실시간 투표율 모니터링 + 미투표자 독려 알림(문자) 워크플로우
  • 공동 링크/개별 링크/QR 진입 방식의 투표 입장 분기
  • 관리자 권한 분리(키 분할 수준의 결과 확정 절차)로 투표 신뢰성 강화

3. 보안·규제 환경 SaaS 구축 경험 — VC 펀드 관리 플랫폼(NICE KYC, VICS 규제 5종, 5계층 보안+DLP+GeoIP), 전자결재 SaaS(6계층 보안, 7 사용자 역할, 전자도장·전자서명) 구축 경험으로 투표 정보 무결성·개인정보 보호 요구를 충족합니다.

4. 1개월 무상 하자보수 + 유지보수 협의 가능 — 산출물 인도 후 1개월간 무상 하자 보수를 기본 제공하며, 필요 시 별도 계약으로 운영 유지보수까지 연속 지원 가능합니다.

PRD (Product Requirements Document)

본 PRD는 공고 본문과 참고 사이트(wrione, uvoteform) 분석을 기반으로 작성된 초안이며, 미팅 시 상세 협의 후 확정됩니다.

1. 프로젝트 배경 및 목적

  • 전자매체 기반의 안전·신뢰·법적 효력을 갖춘 전자투표 솔루션 구축
  • 투표 시작·공지에는 KT 전자투표 시스템을, 투표 종료 후 결과 보관에는 데이터리움 공인전자문서를 연동하여 신뢰성·법적 효력 확보
  • NCP 기반 인프라로 안정성·확장성·운영성을 확보, 유지보수까지 고려한 파트너십

2. 사용자 정의

사용자 유형설명주요 기능
투표자(사용자)투표권을 가진 일반 사용자PASS/간편 인증, 투표 입장, 선택지 선택, 투표 완료, 결과 확인 페이지 진입
관리자투표 이벤트 운영 담당자투표 생성·관리, 투표자 등록·관리, 실시간 모니터링, 결과 집계·확정, 문자 발송, 데이터리움 연동 관리
슈퍼 관리자시스템 운영 총괄관리자 계정 관리, 권한·역할 설정, 감사 로그, 시스템 설정

3. 기능 요구사항

3.1 투표자 인증 및 투표 참여

  • [필수] PASS 휴대폰 본인인증 연동 (개인 식별 + 중복 투표 방지)
  • [필수] 간편 인증 옵션(핸드폰 번호 + 인증번호 등) 지원
  • [필수] 공동 링크 / 개별 링크 / QR 진입 방식 지원 (참고 사이트 분석 결과 반영)
  • [필수] 투표 입장 → 선택지 표시 → 선택 → 확인 → 완료의 단순 플로우
  • [필수] 투표 종료 후 데이터리움 공인전자문서 페이지 자동 연동
  • [필수] 투표 항목 유형: 찬·반, 택일, 다중 선택, 다중 찬반, 기권 옵션

3.2 관리자 기능

  • [필수] 투표 생성: 제목, 기간, 투표 항목, 인증 방식, 투표 방식 설정
  • [필수] 투표자 관리: 명단 등록(엑셀 업로드), 개별/일괄 삭제, 참여 여부 확인
  • [필수] 실시간 모니터링: 투표율, 미투표자 현황, 시계열 그래프
  • [필수] 결과 집계: 실시간/최종 집계, 결과 확정 절차(권한 분리 가능)
  • [필수] 문자 발송: KT 전자투표 연동을 통한 안내·결과 공지, 미투표자 독려
  • [필수] 공인전자문서 연동 관리: 데이터리움 연동 상태, 원본 증명서 발급
  • [선택] 권한 분리(키 분할) 결과 확정: 2인 승인 시 결과 공개

3.3 외부 연동

  • [필수] PASS 본인인증 API 연동 (CI/DI 발급, 중복 식별)
  • [필수] KT 전자투표 시스템 연동 (투표 시작 알림·공지·발송 위임)
  • [필수] 데이터리움 공인전자문서 연동 (투표 결과 보관, 원본 증명)
  • [선택] SMS/알림톡 발송 게이트웨이(별도 또는 KT 연동 활용)
